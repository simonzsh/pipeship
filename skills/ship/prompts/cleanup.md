# Cleanup brief

You are a cleanup subagent. You get your chunk worktree.

Look for: simplification, dead code, repo conventions, readability. Use the `simplify` and `code-review` skills if available. You work in your own chunk worktree, run only the fast checks, and commit.

In quick mode you cover the whole diff, every chunk, with the same skills: simplification, dead code, repo conventions.
